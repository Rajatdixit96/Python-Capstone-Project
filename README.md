# Python Capstone Project

A Python-based data manipulation and analysis project developed using Pandas and NumPy in Jupyter Notebook.

## Project Overview

This project focuses on creating, cleaning, transforming, merging and analyzing employee and project-related data using Python.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Key Tasks Performed

- Created Employee, Project and Seniority datasets
- Converted dictionaries into Pandas DataFrames
- Handled missing project cost values
- Split employee names into First Name and Last Name
- Merged multiple DataFrames using ID
- Calculated project bonuses based on project status
- Updated designation levels based on project status and employee age
- Added Mr./Mrs. based on gender
- Calculated total project cost by employee
- Filtered records based on city conditions
- Exported processed datasets into CSV files

## Key Python Concepts Used

- Pandas DataFrames
- Data Cleaning
- Data Transformation
- DataFrame Merge
- GroupBy and Aggregation
- Conditional Operations
- Lambda Functions
- String Operations
- Filtering
- Loops
- CSV Export
